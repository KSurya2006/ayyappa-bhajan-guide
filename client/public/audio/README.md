# Ayyappa Devotional Audio — Licensing & Usage Documentation

## 1. Copyright Compliance & Provenance
In strict compliance with software and intellectual property policies:
- **No Movie Songs**: Audio tracks from commercial movies (such as *Irumudi* or commercial cinema) are **NEVER** downloaded, ripped, or distributed on this platform.
- **Original Devotional Soundscape**: The included audio file (`ayyappa-devotional.wav`) is an **original, mathematically synthesized Indian classical devotional soundscape** created specifically for the Ayyappa Bhajan Guide web platform using high-precision additive harmonic synthesis:
  - **Sacred Tanpura (తంబురా)**: Authentic Pancham tuning (Pa - Sa - Sa - Sa at D fundamental $146.83\text{ Hz}$ with rich overtones and subtle jawari resonance).
  - **Temple Bells (ఆలయ ఘంటారావం)**: Multi-partial resonant brass bell chimes evoking the sacred sanctum of an Ayyappa Swami temple.
- **Licensing Status**: **100% Royalty-Free, Original & Legally Clear for Web Distribution.**

## 2. Custom Track Drop-in for Project Owner
If the project owner possesses an explicitly licensed studio recording of Ayyappa bhajans (e.g., Harivarasanam or Saranu Gosha), they may place the audio file in this directory:
- Recommended path: `/audio/ayyappa-bhajan.mp3` or `/audio/ayyappa-bhajan.ogg`
- The audio player is designed to automatically detect and prioritize a custom track if provided, with seamless fallback to the synthesized devotional temple ambiance.

## 3. Autoplay & Bandwidth Hygiene
- Modern mobile and desktop browsers enforce strict autoplay policies.
- Playback requires explicit user intent via the **"Play Bhajan / భజన వినండి"** control.
- Asset loading uses `preload="none"` to conserve user mobile data.
